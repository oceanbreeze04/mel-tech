# LA Mahoney · Resume Website

A bold, responsive, one-page resume website for GitHub Pages.

## Publish on GitHub Pages

1. Create a new **public** GitHub repository named `oceanbreeze04.github.io`.
2. Upload `index.html`, `styles.css`, and `script.js` to the root of the repository.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then save.

GitHub will publish the site at [https://oceanbreeze04.github.io/mel-tech/](https://oceanbreeze04.github.io/mel-tech/).

## Customize later

- Edit the visible text in `index.html`.
- Change colors near the top of `styles.css` under `:root`.
- Add LinkedIn or email buttons in the Contact section once those links are ready.

No packages or build tools are required.
